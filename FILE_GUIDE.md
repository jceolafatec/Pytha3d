## 📋 File Descriptions

### Manager Application: `project_manager_pro.py`

**What it does:**
- Desktop application written in Python/Tkinter
- Manages all portfolio projects in a beautiful, organized UI
- Saves data to JSON automatically
- Auto-copies images and 3D models to asset folders

**Key Features:**
- ✅ Tabbed form (Basic Info / Media & Files / Links & Tags)
- ✅ Drag-and-drop ready architecture
- ✅ Browse buttons for file selection
- ✅ Automatic file copying to assets
- ✅ Real-time validation
- ✅ Save/Update/Delete operations
- ✅ Generate HTML snippets
- ✅ Export to JSON + XML simultaneously

**Data Model (what it stores):**
```python
{
  "id": "1",                              # Auto-assigned unique ID
  "title": "Project Name",                # Required
  "meta": "Category · Year",              # Optional
  "description": "...",                   # Detailed description
  "image": "assets/img/file.jpg",         # Auto-copied path
  "model_path": "assets/models/file.glb", # Auto-copied path
  "github_link": "https://...",           # Optional
  "demo_link": "https://...",             # Optional
  "tags": ["3D", "WebGL"]                 # For filtering
}
```

**When to use:**
- Adding new projects
- Editing existing projects
- Managing 3D models and images
- Exporting data for website

---

### Data Storage: `assets/data/projects.json`

**Format:** JSON array of project objects

**What it contains:**
- All your portfolio projects
- Images and model file paths
- Links and tags for each project
- Metadata (category, date, etc.)

**Who creates it:**
- Auto-generated by `project_manager_pro.py` when you click "Export All"

**Who reads it:**
- Website JavaScript (`main.js`) loads this on page load
- Renders project cards dynamically
- Enables search and filtering

**How to backup:**
```bash
# Make a copy
cp assets/data/projects.json backup-projects.json

# Or use Git for version control
git add assets/data/projects.json
git commit -m "Updated portfolio"
```

---

### Website Loader: `assets/js/main.js`

**What it does:**
- Loads `projects.json` from server
- Dynamically renders project cards
- Implements search functionality
- Implements tag filtering
- Handles navigation

**Key Functions:**
```javascript
loadProjects()              // Fetch and load JSON data
renderProjects()            // Create card HTML and insert into DOM
filterBySearch(query)       // Real-time search
filterByTag(tag)            // Filter by clicking tags
applyFilters()              // Combine filters
createProjectCard(project)  // Build individual card
```

**When it runs:**
- Automatically on page load
- When browser window resizes
- When search input changes
- When tag is clicked

**Updated Features:**
- ✅ Loads from JSON (not static HTML)
- ✅ Creates search bar dynamically
- ✅ Renders filter buttons
- ✅ Links to 3D viewer with model path in URL
- ✅ Handles missing images gracefully

---

### 3D Viewer: `project-detail.html`

**What it does:**
- Opens interactive 3D model viewer in browser
- Loads models from URL parameter: `?model=path/to/file.glb`
- Provides interactive controls
- Uses Three.js WebGL rendering

**Power Features:**
- 🎮 Orbit controls (drag, scroll, pan)
- 💡 Adjustable lighting (intensity, color)
- 🎨 Custom background color
- 📷 Screenshot download
- 📱 Fully responsive (desktop/tablet/mobile)
- ⚙️ Auto-scale models to fit viewport
- ⏱️ Auto-rotate animation

**How it's Accessed:**
1. User clicks "View 3D Model" on portfolio card
2. Browser navigates to: `project-detail.html?model=assets/models/model.glb`
3. Page loads and displays model with controls

**Libraries Used:**
```javascript
- Three.js (WebGL rendering)
- GLTFLoader (load .glb/.gltf)
- OrbitControls (interactive camera)
```

**Controls:**
| Control | Action |
|---------|--------|
| **Left Click + Drag** | Rotate model |
| **Scroll** | Zoom in/out |
| **Middle Click + Drag** | Pan |
| **Buttons** | Reset, change lighting, download |

## 🚀 Quick Start Path

1. **Run Manager**
   ```bash
   cd website/tools
   python project_manager_pro.py
   ```

2. **Add Projects**
   - Click "New"
   - Fill form (use Browse for images/models)
   - Click "Save Project"

3. **Export Data**
   - Click "Export All"
   - Generates `assets/data/projects.json`

4. **View Website**
   - Open `website/index.html` in browser
   - Projects load automatically
   - Try search and filters

5. **View 3D Models**
   - Click "View 3D Model" button
   - Opens interactive viewer
