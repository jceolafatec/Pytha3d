# 🚀 Portfolio Manager PRO – Quick Start (2 Minutes)

## Installation: 0 seconds
✅ Already done! No packages to install.

---

## Step 1: Launch Manager (30 seconds)

**Windows:**
```bash
cd d:\Pytha3D_Portfolio\website\tools
start_manager.bat
```
Or double-click `start_manager.bat`

**macOS/Linux:**
```bash
cd ~/pythontools/website/tools  # (or your path)
bash start_manager.sh
```

**Or run directly:**
```bash
python project_manager_pro.py
```

A window opens. You're ready!

---

## Step 2: Add Your First Project (1 minute)

1. Click **"➕ New"**
2. Fill in the form:
   - **Title:** "My First Project"
   - **Meta:** "Design · 2025"
   - **Description:** "A cool project..."
   - **Image:** Click Browse → pick an image
   - **Model:** (optional) Click Browse → pick a .glb file
   - **Tags:** "3D, WebGL" (comma-separated)
   - **GitHub/Demo:** (optional) Paste URLs

3. Click **"💾 Save Project"**

✅ Saved!

---

## Step 3: Export & View (30 seconds)

1. Click **"📄 Export All"**
   - Generates `assets/data/projects.json`
   - Updates website automatically

2. Open `index.html` in your browser
   - 🎉 Projects appear!
   - Search works
   - Tags are clickable
   - 3D models show "View 3D" button

---

## Try These Features

**Search:**
Type "design" in search box → filters projects instantly

**Filter by Tag:**
Click any tag on a card → see only projects with that tag

**View 3D Model:**
If project has a model → click "View 3D Model" → interactive viewer opens

**Reset Filters:**
Click "Reset Filters" button → see all projects again

---

## Next Projects

Repeat steps 1-3:
1. Manager → "New" → Fill form
2. "Save Project"
3. "Export All"
4. Refresh website
